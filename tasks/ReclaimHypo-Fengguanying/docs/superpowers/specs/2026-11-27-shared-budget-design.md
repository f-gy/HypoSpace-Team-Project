# 共享预算实验设计

用户已同意继续验证预算重分配。在新目录隔离实施，不改上一轮冻结结果，不占GPU，不进行训练。

对照三策略：fixed_repeat每题6个、合法空间耗尽后才重复；fixed_stop每题最多6个不同合法答案、耗尽即停；shared_round_robin在全批次6×题数预算内逐题轮流生成不同合法答案、耗尽即跳过，不读每题答案数量。

所有策略使用同一个冻结约束后端。总预算指最终输出名额，不等于相同计算量；记录CPU耗时、solver checks、公共语法检查数。固定配额指标与按实际输出数计算指标分开。空解、超时、预算用不完不填假答案；超时不能标记空间耗尽。

输入只允许id/task/query；query只允许公共规则和观测，不能有gold/pool/S。参考答案仅评分阶段读取。输出按题目身份去重，不把不同题的相同答案当重复。

主评估为原始顺序的19开发题、18内部测试题、3道四节点压力题。额外固定5个顺序种子13/29/47/71/97作稳定性检查，不调参。现有题目已经使用，结果不代表新盲测。

替代方案：只停止重复会改变分母但不增加覆盖；集合微调不能突破合法空间上限。本轮选共享预算，固定策略同时作对照。评测协议若强制每题6个，该方案只能是独立补充实验。
